# Трекер ваги

Односторінковий застосунок для ручного ведення ваги, відсотка жиру та щоденної кількості кроків. Працює повністю в браузері, без сервера й бази даних — усі дані зберігаються локально (`localStorage`) у тому браузері, де відкрито сторінку.

## Можливості

- Ручне додавання записів: дата, час, вага (кг), жир (%)
- Автоматичний розрахунок жиру за лінійною регресією на основі вже введених вимірювань, якщо поле «Жир» лишити порожнім
- Окремий облік кроків за день (з 06.09.2026)
- Історія записів, згрупована по місяцях, з автоматичним розрахунком дельти між вимірюваннями
- Графік у стилі Excel: лінії ваги/жиру на двох осях + стовпчики кроків, з повзунком для вибору періоду перегляду

## Як використати

### Варіант 1 — відкрити локально
Просто відкрийте `index.html` у будь-якому браузері (подвійний клік по файлу).

### Варіант 2 — GitHub Pages
1. Завантажте вміст цього репозиторію на GitHub
2. У налаштуваннях репозиторію відкрийте **Settings → Pages**
3. Виберіть гілку (зазвичай `main`) і папку `/root`
4. Збережіть — за хвилину-дві сторінка стане доступна за адресою на кшталт
   `https://<ваш-акаунт>.github.io/<назва-репозиторію>/`

## Важливо про дані

- Дані зберігаються в `localStorage` **того браузера й того пристрою**, де ви вносите записи. Якщо відкрити сторінку в іншому браузері або на іншому пристрої — там буде «чиста» версія без ваших записів.
- Файл у цьому репозиторії навмисно **без стартових даних** — структура готова, таблиці/графік порожні, вносьте власні показники через форми в застосунку.
- Резервної синхронізації між пристроями немає. Якщо потрібна хмарна синхронізація — знадобиться окреме рішення (наприклад, Google Sheets або невеликий бекенд).

## Python-версія (CLI)

Поряд із веб-версією в репозиторії є `weight_tracker.py` — та сама логіка (запис ваги/жиру/кроків, автоматичний розрахунок жиру, графік у стилі Excel), але як консольний скрипт. Дані зберігаються у `weights.csv` та `steps.csv` поряд зі скриптом.

```bash
pip install -r requirements.txt

python weight_tracker.py add --date 2026-09-06 --weight 69.5
python weight_tracker.py add --date 2026-09-06 --weight 69.5 --fat 35.0
python weight_tracker.py steps --date 2026-09-06 --steps 8500
python weight_tracker.py list
python weight_tracker.py chart                     # створює chart.png
python weight_tracker.py chart --from 2026-08-01 --to 2026-09-30 --out august.png
```

Якщо `--fat` не вказано — жир розраховується автоматично за лінійною регресією на основі попередніх виміряних (не оцінених) записів, так само як у веб-версії.

## Стек

- **Веб-версія (`index.html`):** React + Babel через CDN, без збірки, стилі — вбудований CSS.
- **Python-версія (`weight_tracker.py`):** стандартна бібліотека (csv, argparse) + matplotlib для графіка.
